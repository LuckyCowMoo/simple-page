Typemancer

Typemancer is a game heavily inspired by Slay the Spire and other deck-building roguelikes. Created in response to observing young people's typing proficiency, the goal was to build a genuinely enjoyable game that happens to only accept input through typing—encouraging players to have fun while improving their typing speed passively.

Class Grades Analyser

Class Grades Analyser is a teacher resource that takes standard pupil progress reports as input and safely generates intelligent AI insights about individual students and the class as a whole, without ever exposing identifiable information to an AI company or third party. Read more about how this privacy architecture works on the website.

Circuit Maker

Circuit Maker is a Boolean logic simulation tool. Teachers can use it to export lesson resources and demonstrate how complex systems—like a full calculator with memory and 7-segment displays—can be built entirely from simple logic gates. Students can experiment with gates to build their own circuits, complete challenges to match specific truth tables, and challenge their friends with custom puzzles.

Fire-vs-Fire

Fire-vs-Fire is my final-year undergraduate dissertation project (which earned a First!). It is a universal, locally run AI-filter browser extension accessible even on low-end consumer laptops, paired with a companion backend server running outside the browser environment for deeper hardware access. Fire-vs-Fire is open-source and designed for users to bring their own models; while the prototype AI-detection models currently sit at 75% accuracy with more on the way, secondary object-detection models (such as automatically blurring all spiders) are already highly effective.
